# ALANT — Inicio del proyecto web

Este paquete contiene el contexto necesario para comenzar la web de **ALANT — Software Engineering Studio** con un asistente de desarrollo como Astra Pro.

## Estructura

- `AGENTS.md` — reglas permanentes para el agente de desarrollo. Debe estar en la raíz del repositorio.
- `docs/ALANT-WEB-BRIEF.md` — posicionamiento, identidad visual, contenido y restricciones.
- `docs/IMPLEMENTATION-PLAN.md` — arquitectura, fases de desarrollo y criterios de aceptación.
- `docs/ASTRA-FIRST-PROMPT.md` — prompt para iniciar el trabajo (copiar y pegar en Astra).
- `docs/reference/precision-mint-board.png` — moodboard visual aprobado; referencia estética, **no** diseño final ni asset de producción.

## Cómo empezar

1. Crear una carpeta/repositorio nuevo: `alant-web` (no mezclar con proyectos anteriores).
2. Copiar `AGENTS.md` y la carpeta `docs/` dentro de esa raíz.
3. Abrir el repositorio en el entorno donde Astra Pro pueda leer y modificar los archivos.
4. Copiar el contenido de `docs/ASTRA-FIRST-PROMPT.md` en una conversación nueva con Astra.
5. Pedir que trabaje únicamente el primer hito: base técnica y homepage.
6. Revisar diseño en escritorio y móvil antes de avanzar a las demás páginas.

**No conectar todavía el dominio de producción**, ni publicar una versión incompleta. Validación marcaria/comercial pendiente por coincidencia de denominación en Brasil.
