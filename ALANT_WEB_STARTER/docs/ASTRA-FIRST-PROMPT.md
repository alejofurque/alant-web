# Prompt inicial para Astra Pro

Actuá como mi ingeniero senior frontend, arquitecto Angular y diseñador web especializado en estudios tecnológicos B2B premium.

Vamos a desarrollar la web real de **ALANT — Software Engineering Studio** dentro de este repositorio. La identidad visual elegida es **Precision Mint (Engineered Systems)**. El idioma inicial es español y debe quedar preparada para una futura versión en inglés.

**Antes de escribir código:**
1. Leé COMPLETOS `AGENTS.md`, `docs/ALANT-WEB-BRIEF.md` y `docs/IMPLEMENTATION-PLAN.md`.
2. Revisá visualmente `docs/reference/precision-mint-board.png` si disponés de acceso a imágenes.
3. Inspeccioná los archivos existentes y las versiones de herramientas. Si la carpeta está vacía, inicializá el proyecto con una versión estable y soportada de Angular.
4. Decime muy brevemente qué arquitectura vas a usar y qué problemas potenciales encontrás.

**Después, ejecutá SOLAMENTE el Hito 0 y el Hito 1** del plan: setup técnico y una homepage de alta calidad visual. No desarrolles por ahora todas las páginas internas, no inventes casos de éxito ni hagas un diseño genérico de agencia IA.

Requisitos críticos:
- Angular + TypeScript, Tailwind CSS v4 y arquitectura mantenible.
- SSG/prerender en las rutas corporativas para SEO y rendimiento.
- Español como lengua fuente y estructura preparada para inglés, sin publicar textos ingleses incompletos.
- Diseño fiel a la dirección Precision Mint: graphite `#11191B`, offwhite `#F2F4F1`, mint `#97E5B3`, slate `#65787C`, Geist Sans + Geist Mono como candidatas.
- Wordmark temporal ALANT, no logo final.
- Hero memorable con recursos visuales propios y diagramas modulares auténticos; no uses una imagen del moodboard pegada como fondo.
- Responsive de verdad, accesibilidad, navegación funcional y animaciones discretas.
- CTAs sin URLs falsas; si falta un medio de contacto real, implementá un fallback transparente o dejá la dependencia señalada para que la confirmemos.

**Validación:** ejecutá el build y las pruebas posibles; si tenés navegador, revisá desktop y mobile e iterá. Indicá claramente qué verificaste y qué no pudiste verificar.

**Importante:** al terminar la homepage, detenete. Quiero revisar el diseño antes de continuar con Servicios, Proyectos, Estudio y Contacto. No publiques el sitio ni modifiques el dominio.
