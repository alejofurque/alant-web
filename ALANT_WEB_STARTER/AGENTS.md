## Principios no negociables
- El posicionamiento es **Software Engineering Studio**.
- Identidad aprobada: **Precision Mint / Engineered Systems**.
- Sitio inicial en español profesional, claro y neutral para Argentina y LATAM; arquitectura preparada para inglés.
- Diseño premium, moderno y preciso. Evitar estética de chatbot, cripto, sci-fi, gradientes violetas, circuitos, ilustraciones con robots y apariencia de plantilla.
- No inventar clientes, alianzas, casos reales, resultados, porcentajes, testimonios, años de experiencia ni miembros del equipo.
- El nombre ALANT no implica marca registrada o uso internacional legalmente confirmado.
- No generar ni dar por aprobado un isotipo final: usar temporalmente un wordmark tipográfico «ALANT».
- No depender de fondos con capturas de referencia; implementar layout, componentes y recursos gráficos reales con HTML/CSS/SVG propios.
- Priorizar calidad visual, tipografía, espaciado, accesibilidad, rendimiento y conversión.
- Respetar `prefers-reduced-motion`; animaciones suaves y no intrusivas.
- Evitar dependencias innecesarias, código duplicado, componentes gigantes y sobrearquitectura.
- No exponer secretos; no publicar en producción ni modificar DNS sin autorización explícita.

## Proceso de trabajo
- Primero inspeccionar el repositorio y presentar un diagnóstico breve.
- Mantener un plan de pasos verificables. Realizar una fase a la vez.
- Comenzar por configuración del proyecto y homepage; no construir las cinco páginas de una sola vez.
- Antes de añadir paquetes, comprobar versión real del proyecto y compatibilidad con documentación vigente.
- Usar componentes reutilizables con Angular standalone, TypeScript estricto y CSS tokens centrales.
- Probar build, navegación, enlaces y responsive cuando el entorno permita ejecución.
- Reportar archivos editados, comandos corridos, resultado de comprobaciones y pendientes reales.
- Si el entorno no dispone de navegador/preview, avisar; no afirmar que el diseño visual fue inspeccionado.

## Prioridades de calidad
1. Confianza de una empresa B2B que evalúa un proveedor técnico.
2. Claridad: qué hacemos, para quién y cómo contactarnos.
3. Diseño distintivo y consistente con Precision Mint.
4. Rendimiento, SEO e internacionalización futura.
5. Código limpio y simple de mantener.
